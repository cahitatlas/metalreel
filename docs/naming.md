# Why "MetalReel"

Candidates checked (November 2026) against GitHub repository search, the npm registry and a web search:

| Name | Finding | Verdict |
|---|---|---|
| **metalreel** | no GitHub repos, npm name free, no product with that name | **chosen** |
| metalmotion | free on GitHub and npm; close to Apple's *Motion* app | runner-up |
| silicareel | free everywhere; the Apple Silicon reference is subtle | fallback |
| framecore | npm free, but an existing GitHub org and several repos | crowded |
| swiftmotion | existing SwiftUI animation library (Product Hunt launch) | collision |
| nativemotion | existing React Native animation library | collision |
| reelforge | several AI-video repos, npm name taken | collision |
| remotion-native / remotion-metal | free, but read like official `@remotion/*` packages | avoided |

Reasons for MetalReel: short, pronounceable, searchable, says *Metal* (Apple GPU) and *reel* (video) without
borrowing the Remotion trademark. Compatibility is described in the tagline and keywords
("native macOS renderer for Remotion projects"), not in the name.
